1Bowerkeep — first direction

The repo is pre-implementation, so nothing here is a recreation: it is built from the MVP plan's vocabulary (exact printing, physical copy, indicative value, Collection / Decks / Scan / Value) and the A$20 threshold. Direction is collector-warm: paper ground, ink text, Lora for card names, Archivo for UI, mono for set codes and money. Card art is a placeholder — real art comes from cached Scryfall URLs at runtime. 1a is clickable: shutter advances the scan flow, chips filter, rows open, Move… relocates a copy. Scan now uses the 1c overlay — full-bleed camera, corner brackets, tally in the corner, readout on one line.
